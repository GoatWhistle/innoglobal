# Проверка сцены «Магистраль»

Дата: 12.11.2026. Ветка main, базовый SHA b6a8336, изменения не закоммичены.
Страница: `/work/design/ds/pipeline.html`, код в `work/design/ds/pipeline/`.

## Что построено

Труба из трёх слоёв (сталь, минеральная вата, алюминиевый кожух) со ступенчатым разрезом, два
фланцевых стыка с болтами, пять опор на фундаментах, шесть датчиков с кольцом состояния.
Нефть в разрезе движется вдоль оси. Утечка: отверстие, струя из частиц со сглаживанием в экранном
пространстве, брызги, растущая лужа, наезд камеры. Фронты волны давления идут кольцами по трубе.
Расчёт, панель и графики берутся из общего Worker без изменений.

| Уменьшенное движение | `?motion=reduce`, вставка через поле, итоговая версия | Время сцены стоит на 0, 949 частиц заморожены между двумя замерами, лужа и наезд показаны сразу |
| Без 3D | `?nogl=1` в iframe | Показана SVG-схема, расчёт работает |
| Геометрия и струя | `node --import ./test-imports.mjs --test pipeline.test.mjs` | 5 тестов пройдены |

Скорость измерена на одной машине разработчика (macOS, Chrome); на других не проверялась.
`?motion=reduce` включает тот же путь, что системная настройка; сама системная настройка не переключалась.

## Сверка с референсами

Открыта страница референса №1 (Drain Pipe Oil Discharge): нефть там бьёт широким рваным веером из
жгутов и брызг. После сверки струя переделана: шесть расходящихся жгутов, отдельные капли, 42 %
частиц отскакивают всплеском, вокруг лужи брызги. В кадре стало около 930 частиц; медиана кадра
8,3 мс, p95 10,0 мс, рендер p95 5,7 мс (1483 px, DPR 1,75).
Страница референса №4 (Dandify) не открыта: расширение Chrome запрещает действия на этом домене.
Референс №2 (SLB) просмотрен по пяти кадрам на авторской странице Motion Giraffx: голая сталь с живыми
царапинами и потёртостями под мягким студийным светом, течь показана брызгами из трещины, датчики —
нумерованными точками. После сверки в текстуры кожуха и стали добавлены царапины и потёртости
(нормали и шероховатость); медиана кадра осталась 8,3 мс, p95 10,0 мс при 940 частицах.
Видео №3 и №5 лежат только на Vimeo; сайт показал проверку на бота, она не проходилась.

## Ограничения

Геометрия условная: 12 км показаны отрезком около 17 единиц. Струя, брызги и лужа иллюстративны и
не влияют на расчёт: это частицы с баллистикой, а не решатель гидродинамики. Частицы не сталкиваются
с трубой и опорами. Потеря контекста WebGL не воспроизводилась.
