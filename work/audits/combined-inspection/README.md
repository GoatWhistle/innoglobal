## Что изменилось

Очередь и локальная труба из «Осмотра участков» объединены с датированным сравнением и
знаковой разницей. Справа одна панель выбранного сегмента. Дата обследования обновляет
график, разницу, базовое значение, горизонт и предупреждение о превышении базы.

По умолчанию видны выбранный сегмент и три соседа с каждой стороны. Можно перейти ко всей
трубе или выделить диапазон; труба и графики получают одну область. Диапазон сохраняется
в URL и восстанавливается после перезагрузки. При отсутствии ВТД показан паспортный номинал.

В совмещённом режиме наложение показывает оба источника целиком. Режим «Рядом» разделяет
дорожки. Подвижная граница сохранена в отдельном «Столе сравнения».
Общий ComparisonPanel переиспользуется обеими композициями. Труба и графики получили
компактную высоту на существующих токенах; новые палитры и шрифты не добавлены.

Команда финального браузерного прогона из `frontend/`:

```bash
E2E_BASE_URL=http://localhost:18080 npm run e2e -- variants.spec.ts variants-edges.spec.ts combined-inspection.spec.ts --grep 'comparison|inspection|review fixes|difference readouts|gallery pairs|empty queue|increased text' --workers=2
```

Начальный запрос с якорем `^` выбрал только два edge-теста; это не было покрытием матрицы.
Фильтр исправлен, матрица прошла 42 проверки на dev, затем весь затронутый набор из 50 проверок
на финальной сборке Compose. Повторная общая проверка frontend выполнена после компактной
компоновки управляющих элементов. Motion использует существующие компоненты: значения
и клавиатурное перемещение обновляются сразу; сценарий с reduced motion прошёл.

Hook не нашёл детерминированных проблем в ComparisonPanel. Отдельный повторный детектор не
запускался. Итог независимого визуального просмотра: [finish-review.md](finish-review.md).
Сверка с дизайн-системой: [documentation.md](documentation.md).

Проверен Chromium на локальном стенде. Другие движки, физические устройства и удобство для
реальных инженеров этим прогоном не измерялись. Существующее предупреждение о 3D-чанке
567,88 kB до gzip сохраняется. Качество модели и покрытие P10/P90 не переоценивались.
