# Material workspace: проверка реализации

Дата: 2026-11-15. Ветка: `feat/frontend`, базовый HEAD: `4db9fdac6367f238391b2984791fd99d8423a6f3`.
Изменения локальные. Frontend пересобран через Docker buildx bake и обновлён на
`http://localhost:18080`; backend и API-контракт не менялись.

## Объём

Реализована [согласованная композиция](../../screens/material-workspace.md): физическая труба
в обеих темах, очередь/группы, профиль и подробности участка, мобильный Drawer,
единая система страниц данных и модели. Исходный каталог `work/design/ds/` не изменялся.

Признаки участка используют существующий endpoint. Глобальная важность подписана отдельно;
локальные вклады не заявлены. CSV остаётся построчным. Группы не меняют ранги API.

это не замер надёжности конкретного GPU. Все e2e из material-workspace используют reduced motion.

## Визуальные исправления

1. На 375px длинное имя модели пересекало следующую метрику. Имя получило собственную строку.
2. На 768/1024px ссылка на проверку модели выходила за колонку данных. Добавлены переносы
   и ограничение по ширине. Для обеих границ добавлены браузерные проверки.

Повторный независимый просмотр всех 16 `review-*` подтвердил оба исправления в двух темах.
Новых существенных проблем в нижних разделах графиков, моделей, ограничений и таблиц не найдено.

## Ограничения проверки

Native Chrome через computer use показывал серую поверхность после навигации и перезагрузки.
Этот путь визуально подтвердить не удалось; проверены Playwright Chromium и собранный контейнер.
Ширины 1920/2560px, масштаб 200%, Firefox и Safari в этом проходе не проверялись.
Английский UI не включался по действующему решению пользователя; паритет словарей проверен.

Остались предупреждения существующего кода: Biome descending specificity в Table,
PostCSS без `from`, размер 3D-чанка выше порога Vite. Они не остановили verify/build.
Установка dev-сервера на занятый 5179 не состоялась; проверка разработки использовала 5187.

`frontend/DESIGN.md` обновлён вместе с PRODUCT, COMPONENTS и design-decisions.
`frontend/.impeccable/design.json` содержит семь образцов компонентов и ссылки на CSS-токены;
существование ссылок проверено. Preview панели Impeccable не проверялся. Значения токенов
остаются только в CSS согласно frontend/AGENTS.md, поэтому frontmatter не дублирует палитру.
