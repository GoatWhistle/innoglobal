Движение проверено правилами токенов и сценарием reduced motion; числа обновляются напрямую.
Основные сценарии проверены указателем и клавиатурой. Общие оси, источники, фиксированные шкалы,

ширинами и 200% текстом. На мобильных экранах компактный прогноз, предупреждение о превышении
базы и главное действие предшествуют подробным фактам.

## Границы и сбои прогона

P10/P90 остаются некалиброванными, целевые ВТД скрыты, первые 10% означают очередь проверки.
Положительная разница прогноза и базы показана как повод проверить модель. Сечение скалярное,
угловые дефекты не реконструируются. Шкалы берутся по всей трубе и не меняются при выборе.

Физические сенсорные устройства и другие браузерные движки не проверялись. Отдельного
инструментального профилирования производительности не было. Сохраняется предупреждение сборки
о 3D-чанке больше 500 kB. Его размер в финальной сборке 567,88 kB до gzip.

При первом перезапуске Compose отсутствовала переменная порта, поэтому frontend временно
оказался на 8080; запуск исправлен с `FRONTEND_PORT=18080 BACKEND_PORT=18010`.
Неуспешный стартовый прогон сохранён в `port-startup.log`. При пакетной съёмке случались
ошибки Chromium `Page.captureScreenshot`; повторяется только захват изображения, проверки
взаимодействий не ослаблены. Итоговые снимки получены успешно.

Встроенный браузер не открыл галерею: `The browser access host is unavailable`.
Системная команда `open` для ссылки галереи завершилась с кодом 0. Состояние видимой вкладки
через этот инструмент недоступно; сама страница и её изображения проверены браузерными тестами.

Для ежедневной работы рекомендован сканер: одна ось связывает трубу и все доказательные дорожки.
Атлас удобен для поиска групп, стол сравнения для проверки расхождений. Это проектная рекомендация;
сравнительное исследование с инженерами не проводилось.
