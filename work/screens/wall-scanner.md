# Wall scanner: approved direction

2026-11-14. Mode: Operate. Audience: hackathon jury, then inspection engineer.
Approved: evolve current world, full design system plus one interactive flagship screen, HTML catalog,
synthetic data, scanner signature. No new name/logo, ML, real data integration or product API.

The first viewport connects a physical pipe and movable section to a dimensioned minimum-wall diagram
and longitudinal thickness profile. The memorable action is moving the cut and seeing one segment
selected everywhere. The page uses the existing Onest / graphite / paper world, no new visual-world
selection. Code-led implementation: the real WebGL interaction is the visual authority.

Input is two synthetic examples for the new organizer case. Selection is shared by 3D, range, field,
profile and ranking. No false measured corrosion surface, target VTD or validation score. Missing data
and failure states remain usable. Future data, segment, validation and inspection screens are diagrams.

Acceptance: both cases, partial segment, invalid coordinates, top 10%, keyboard, themes, missing data,
recovery and WebGL fallback; visual matrix 375/1280/1440 in both themes. Details and actual results:
work/audits/scanner/README.md. Data contract: work/design/ds/scanner/README.md.
