# Five engineering workspaces

Mode: Operate. Authority: work/design/variants/brief.md, supplied 2026-11-15.
Build all five specified directions, code-led, with no preliminary selection. Existing product and catalog stay available.

## Direction contract

THESIS: compare five ways to inspect the same ten-metre forecast, with one URL selection and real API data.
OWN-WORLD: existing Onest, graphite/paper, steel/rust/amber, precise axes and dimension marks. Reuse semantic tokens and controls.
STORY: identify a thin group, select it, compare evidence, inspect the queue. Forecast is always a segment minimum; no invented angular map.
FIRST VIEWPORT: scanner = long side elevation plus aligned tracks and right readout; atlas = dense ordered segment field plus local detail; comparison = aligned observed/forecast strips and signed difference; inspection = left queue, local pipe and right evidence; drafting = engineering sheet, longitudinal drawing and dimensioned section. Essential value and primary action remain near the top on mobile.
FORM: five user-pinned compositions; no random seed or preselection. Gallery has real captures, context controls, direct links and two synchronized live views on wide screens.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Implementation and evidence contract

- Common URL: pipe, segment, from, to. Preserve all on view switch. Validate against API rows, never array indices.
- Fixed colour domain per complete pipe, unaffected by zoom or priority filter. Interval layer has its own stated unit/domain.
- VTD observations stay distinct from nominal; no target observations or invented intermediate dates. UZT is not returned at segment level: explicitly unavailable, never represented by VTD symbols.
- Relative priority is the existing rank, never recalculated or renamed risk. Export uses existing endpoint.
- Compare latest or selected real VTD against target forecast; case2 uses nominal. Positive deltas are labelled and link to the model.
- Atlas uses all rows without aggregation; keyboard roving selection and 44px touch cells, rows scroll on small screens.
- States: API loading/error/retry, empty profile, missing observations/elevation, invalid URL. Motion uses existing tokens and reduced-motion; numbers never tween.
- Verify: frontend verify; Playwright both pipes, five variants, themes, mobile/desktop, keyboard, deep links, comparison, filtering, zoom, queue and API states. Real same-context captures feed gallery.
