К содержанию

Основы
интерфейса

Труба сама становится интерфейсом. Экраны показывают её с трёх расстояний: трасса, развёртка стенки и сечение. Выбранный сегмент сохраняется при переходе между ними.

Открыть трубуДетали трубыОбщий набор

  1. Цвет задаёт приоритет

    Данные нейтральные. Янтарь выделяет участки для проверки. Бордовый обозначает ошибку или нарушение известного критерия; сам прогноз не означает аварию.

  2. Две личности

    Тёмная тема: ночной диспетчерский зал, глубина и блеск нефти. Светлая: инженерный чертёж, тушь и штриховка. Структура общая.

  3. Линия раньше тени

    Слои разделяет волосяная линия в  px. Тень есть только у того, что парит над страницей.

  4. Два темпа

    Интерфейс отвечает за – мс. Сцена течёт вязко, – мс.

Стиль от трубы

Три приближения к одной трубе. Масштаб меняет камера, страница остаётся на месте. У каждого масштаба один ведущий источник стиля, остальные молчат.

  1. 1. Трасса

    Вся труба, пикеты, полоса сегментов. Тонкие места видны на металле. Ведёт сцена; панели поверх неё матовые.

    Трасса

  2. 2. Развёртка

    Стенка раскрывается в лист: ось в километрах и ось в часах по окружности. Профиль стоит на той же оси. Ведёт чертёж поверх металла.

    Развёртка

  3. 3. Сечение

    Разрез в выбранном сегменте, кольцо стенки с размерами и одна крупная цифра. Ведут чертёж и редакция.

    Сечение

  4. Шкала стенки

    Сталь, ржавчина, янтарь: --wall-steel, --wall-rust, --wall-amber. Шкала относительная, порога нет, цвет не означает аварию.

    Шкала

  5. Детали из трубы

    Бирка, маркировка, полоса сегментов, размерная линия, клавиша камеры, матовая панель, штамп листа.

    Каталог деталей

Как собрать экран

Десять решений по порядку. Каждое уже принято в основах, экран только выбирает готовое.

  1. Вопрос экрана

    Один вопрос, на который экран отвечает за секунду. Главный: где стенка тоньше и какие участки проверить первыми.

    Экран трубы

  2. Каркас

    Сцена с панелью, список с деталью или параметры с предпросмотром. Ширина экрана заполнена.

    Каркас и сетка

  3. Плотность

    Обычная по умолчанию. Плотная только в таблицах инженера с мышью.

    Плотность

  4. Показания

    Каждое число через Readout или Stat: единица, точность, модель рядом, свежесть.

    Числа

  5. Графики

    Замер сплошной, прогноз пунктиром. Интервал показывается только при наличии данных.

    Графики

  6. Дата

    Каждый замер связан с обследованием. Прогноз имеет дату T и исходную точку.

    Будущие экраны

  7. Приоритет

    10% сегментов с наименьшей прогнозной толщиной. Подпись объясняет правило отбора.

    Список проверки

  8. Пять состояний

    Загрузка, пусто, ошибка, устарело, нет сети. Ни одно не тупик.

    Обратная связь

  9. Две личности

    Светлая тема получает детали чертежа через токены. Компонент тему не знает.

    Подписные детали

  10. Слова и клавиши

    Термины из словаря, сочетания клавиш из общей карты, фокус по порядку чтения.

    Словарь
