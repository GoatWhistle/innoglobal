отражениями. Название — текстура на изогнутой поверхности; на телефоне читаемый слой текста.

Поток иллюстративный, не гидродинамическая симуляция; новая геометрия — только дизайн-прототип.
Оригинальный production-движок и API не изменены. CDN Three.js нужен для живого рендера.
