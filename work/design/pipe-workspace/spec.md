# Рабочее пространство трубы

Режим: Operate. Прототип Superdesign, без изменения production18080.
Труба ведёт композицию. Слева компактные метрики выбранных10м, очередь раскрывается по запросу.
Справа чат выезжает поверх сцены; ширина сцены и размер трубы не меняются.
Ниже прогноз/P10/P90 и выбранная база ВТД, рельеф. Графики выбирают сегмент.
Сохраняются обе трубы, история ВТД, номинал, горизонт, приоритет, параметры сегмента,
паспорт, источники, таблица признаков и медиан, глобальная важность, выгрузки.
Функции просмотра: вращение/волны, разрез, развёртка прогноза вдоль трубы, сброс,
фокус на трубе; шаг по сегментам, переход по расстоянию, очередь/группы, локальный/полный профиль.
Чат: контекст сегмента, вопросы, черновик, история, scope. Ответы не имитируются:
исходный сервер ассистента недоступен; прототип честно показывает отсутствие подключения.
На375px сцена идёт перед метриками, чат полноширинный поверх сцены, графики ниже.
Клавиатура: focus-visible, Esc закрывает чат, фокус возвращается к открывшей кнопке;
фокус внутри drawer не уходит под него. Reduced motion выключает выезд и старт потока.

Источник: localhost18080/?view=route&segment=1273, снимок4758af03febd.
1273 отсутствует у выбранной первой трубы; источник выбирает131 (1310–1320м).
Все данные прототипа — фиксированный снимок реальных API двух труб, не live connection.
Визуал нефти и геометрия не гидродинамическая модель и не точная форма дефектов.
