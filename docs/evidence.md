# Что подтверждено проверками

Стенд обслуживает готовый прогноз 2000 сегментов из реального DuckDB и CSV.
Точность на скрытом контрольном ВТД целевых кейсов не измерена.

## Проверен ли цикл инженерного помощника?

**Закреплено:** `cd backend && uv run pytest tests/unit tests/integration` — 143 теста,
включая 15 проверок, добавленных для помощника и авторизации SDK. Прикладные проверки
заменяют модель локальным провайдером; интеграционные читают реальные DuckDB/CSV и карточки.
Проверяются выбор инструмента, ссылки на доказательства, ограничение числа запросов,
отмена, совместимость карточек и NDJSON endpoint. `ruff check`, `ruff format --check`
и `mypy` проверяют backend. Прогон: 15.11.2026.

Frontend `npm run verify`: 36 правил, типы, линтер, 382 теста и сборка прошли с обновлённым
OpenAPI-контрактом. Есть предупреждения существующих CSS-селекторов, PostCSS и размера чанка.
Реальный вызов `gpt-6.1-sol`, качество инженерных выводов и время ответа модели не измерены.

## Совпадает ли экспорт с источником?

**Гипотеза:** API выдаёт один прогноз для каждого ожидаемого сегмента и сохраняет result.csv.

**Команда:** `cd backend && uv run pytest tests/integration/repository/duckdb/test_snapshot_source.py -q`.

**Выборка:** обе трубы: 525 и 1475 сегментов. Проверяются все ключи и сетки; текст экспортированного
result.csv сравнивается целиком. Значения API дополнительно сравниваются с источником на первых,
средних, последних и крайних приоритетных сегментах.

**Предел:** совпадение с артефактом не доказывает правильность прогноза относительно скрытого ВТД.

## Совместимы ли сохранённые пары с историческим разбиением?

**Гипотеза:** архивные наблюдения можно связать с текущими сегментами исторической выборки.

**Команда:** `cd backend && uv run pytest tests/integration/repository/duckdb -q`.

**Выборка:** 55 пар case1 и 525 пар case2 из `chart_data.json`, сверенных с `train_dataset.csv`.
У case1 проверены все ключи и наблюдения, пересчитаны r²=0,3434524851 и MAE=0,3506181818 мм.
Метрики отдельного прогона не смешиваются с отчётом выбранного ens_blend.
У case2 гипотеза не подтвердилась: наблюдения расходятся, поэтому точки и метрики сравнения
не выдаются. Это отрицательный результат проверки совместимости, а не оценка точности.
Статус: **Закреплено** интеграционными тестами, включая изменённое наблюдение и повреждённую пару.

**Предел:** совпадение последовательности наблюдений и метаданных разбиения не восстанавливает
отсутствующий манифест архивного обучения. На целевое скрытое ВТД результат не переносится.

## Как воспроизвести браузерную проверку?

```bash
cd frontend
E2E_BASE_URL=http://localhost:18080 npm run e2e
```

Продуктовый тест проверяет обе трубы, выбор стрелками и Home/End, связь с данными API,
сечение, приоритеты, CSV, график и таблицу исторических пар, восстановление API, сохранение выбранной трубы, отсутствие переполнения,
axe WCAG AA, reduced motion и недоступный WebGL. Снимки создаются при прогоне.
Это проверка Chromium; физический сенсорный экран и другие движки отдельно не проверялись.

## Как выровнены дистанции ВТД?

Пропуски 2018 и 2022 года трубы 1250022871 сопоставлены по кольцевым сварным швам
(`align.window_shifts(..., "weld")`, 15.11.2026): швы двух пропусков связаны монотонной цепочкой
с плавным сдвигом, каждую пару подтверждают совпавшие дефекты. Найдено 313 швов в 2018 году,
497 в 2022 году, 293 пары. Сдвиг дистанции 2022 относительно 2018 плавно меняется вдоль трубы
от −6,7 м в начале до +3,4 м в конце. Признаки прошлого пропуска нормализуются: минимальная
толщина берётся медианой по 5 и 21 сегменту, число дефектов делится на число дефектов пропуска
(разные снаряды видят 2 257 и 25 989 дефектов на одной трубе).

## Как связаны режим и рельеф с главными признаками?

Корреляция Спирмена по 690 обучающим парам с прошлой ВТД (`features.build_all()`, 15.11.2026).
С числом дефектов на прошлой ВТД: возраст 0,41, время после ингибирования −0,41, температура 0,29,
обводнённость 0,23, давление 0,23. С потерей металла: возраст 0,20, время после ингибирования
−0,20, отметка 0,18, температура 0,13, обводнённость 0,13, низинность −0,12. Между числом
дефектов и прошлой толщиной −0,84. Химия образцов-свидетелей на обучающих трубах принимает два
значения и как признак не используется; по самим образцам хлориды ускоряют коррозию (0,30),
бикарбонат замедляет (−0,18), см. README-ML.md.
