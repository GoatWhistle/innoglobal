# Дашборды

**Читайте, если** собираете свой набор графиков · **Связано:** [Первые 15 минут](guide.md) ·
[Помощник](assistant.md)

---

Кнопка «Дашборды» в осмотре трубы открывает `/dashboards` с выбранной трубой, участком и диапазоном. Возврат к трубе сохраняет этот контекст. Дашборды доступны в светлой и тёмной темах.

При первом открытии появляется «Обзор трубы»: прогноз с P10/P90 и базой сравнения, разница с базой и очередь проверки. «Новый дашборд» создаёт пустое полотно. В библиотеке доступны также таблица участков, метрика выбранного участка, рельеф и карта толщины. Превью использует текущий профиль API. Если измерений нет, график не заполняет пропуски нулями; паспортный номинал обозначен отдельно.

В режиме редактирования можно менять названия и ширину блоков, переносить их за рукоятку, удалять и отменять последнее изменение. Размеры S/M/L/XL занимают 3/6/9/12 колонок; S доступен метрике. На телефоне блоки идут одной колонкой. Стрелки на сфокусированной рукоятке перемещают блок, Escape отменяет перенос мышью.

База сравнения, диапазон и выбранный участок общие. Наведение на график показывает курсор на остальных графиках; выбор участка синхронизирует представления. «К выбранному участку» центрирует диапазон без изменения его ширины. Очередь и таблица ограничены диапазоном; карта толщины остаётся обзором всей трубы.

## Сохранение

Конфигурация сохраняется в localStorage этого браузера. Определения виджетов отделены от размещений: удаление блока с полотна не удаляет его из библиотеки. Числовые измерения в конфигурацию не копируются — они приходят из API при открытии.

Ошибка записи оставляет изменения в памяти и предлагает повторить сохранение. Неизвестная или повреждённая версия не перезаписывается до явного сброса. Данные между устройствами не синхронизируются; очистка хранилища браузера удаляет дашборды.

## Создание с агентом

Интерфейс поддерживает запрос, ожидание, отмену, предпросмотр, уточнение, выбор поддерживаемого вида, сохранение определения в библиотеку и добавление на полотно. `WidgetGeneratorPort` принимает запрос и контекст трубы, снимка, участка, диапазона и базы. Его результат проверяется до отображения. Числа берутся из профиля, произвольный код не исполняется.

Текущий AssistantEvent API не возвращает структурированный виджет. Поэтому в рабочем приложении вкладка «Создать с агентом» показывает недоступность и предлагает библиотеку. Обычные текстовые ответы чата не преобразуются в графики. Успешный сценарий генератора проверяется тестами с подставным транспортом только в тестовой среде.

Первая версия ограничена семью зарегистрированными инженерными видами. Они дают линейные профили, столбцы разницы, горизонтальные полосы толщины, таблицу, метрику и сетку. Свободные формулы, SQL и произвольные поля внешних источников не принимаются. Для подключения настоящего генератора достаточно адаптера к согласованному структурированному ответу; backend такого ответа пока не отдаёт.
