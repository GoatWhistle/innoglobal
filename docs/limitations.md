# Ограничения

Что прогноз и стенд не устанавливают. Каждое ограничение помечено тем, откуда оно известно.

**Читайте, если** принимаете решение по прогнозу · **Связано:** [Валидация](evidence.md) ·
[Прогноз](model.md)

---

## Чего прогноз не доказывает?

| Ограничение | Откуда известно | Последствие |
| --- | --- | --- |
| Точность на целевых трубах не измерена: контрольное ВТД на дату прогноза в демо-наборе скрыто | Состав данных | Метрики валидации относятся к историческим парам, а не к целевым трубам |
| Труба с прошлым ВТД: сдвиг одометра целевой трубы интерполируется по соседям нитки с точностью около метра | Валидация: при ошибке ±1 м r² падает до 0,71–0,74, при выравнивании только по соседям — до 0,29 | На целевой трубе стоит ждать r² ниже 0,75 |
| Труба без ВТД: позиции дефектов слабо переносятся между трубами | Валидация: без валидационной трубы в обучении r² падает до 0,05 | Прогноз — оценка уровня с осторожной формой, а не карта дефектов; разброс по трубе мал, std 0,04 мм |
| P10–P90 не откалиброваны по покрытию | Покрытие не измерялось | Интервал не гарантирует попадание истинной толщины |
| Важность признаков глобальная | Метод | Причины утонения конкретного сегмента не установлены |
| Прогноз — минимум в сегменте 10 м | Постановка задачи | Распределение стенки по окружности неизвестно; сечение и развёртка иллюстративны |
| Сегмент без дефектов в отчёте ВТД получает модальную толщину пропуска | Метод | Отсутствие дефекта в отчёте не равно измерению всей стенки |
| Приоритет проверки — относительный порядок | Правило отбора | Это не вероятность отказа и не допустимая толщина |

## Чего нет в продукте?

- Загрузки собственных выгрузок через интерфейс: данные кладутся в `data/`, затем перезапускается
  конвейер.
- Произвольной даты прогноза в интерфейсе: даты заданы в конфигурации конвейера.
- Переобучения и редактирования обследований из интерфейса.
- Пользователей, ролей и журнала действий: см. [безопасность](security.md).
- Синхронизации дашбордов между устройствами: они хранятся в браузере.

## Что не проверялось?

Работа на физических сенсорных устройствах и в движках, кроме Chromium; производительность 3D-сцены
на слабых машинах; качество ответов помощника на реальной языковой модели и время её ответа.
