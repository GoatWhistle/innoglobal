# Словарь

Термины интерфейса, API и документации.

## Труба и обследования

**ВТД**:
Внутритрубная диагностика: снаряд проходит по трубе и регистрирует дефекты стенки, их положение,
глубину и остаточную толщину. Один проход называется пропуском.

**УЗТ**:
Ультразвуковая толщинометрия: точечный замер толщины стенки снаружи трубы.

**Образец-свидетель**:
Пластина, установленная в поток на известный срок; по потере её массы оценивают скорость коррозии.

**Сегмент**:
Интервал трубы длиной 10 м, для которого считается один прогноз. Последний сегмент может быть
короче. _Не путать_ с точкой замера: одному сегменту соответствует много измерений.

**Номинальная толщина**:
Проектная толщина стенки по паспорту. Для трубы без обследований — отправная точка прогноза.
_Не путать_ с измеренной толщиной.

**Браковочная толщина**:
Паспортный уровень, ниже которого стенка требует решения по ремонту. В интерфейсе — справочная
линия, а не автоматический статус.

**Сдвиг одометра**:
Расхождение дистанций одного и того же места трубы в разных пропусках ВТД; достигает нескольких
метров и совмещается по сварным швам.

## Прогноз и оценка

**Минимальная остаточная толщина**:
Наименьшая толщина стенки в сегменте на дату прогноза, мм. Не описывает распределение
повреждения по окружности. _Не говорим_: средняя толщина, глубина дефекта.

**Дата прогноза**:
Дата, на которую оценивается минимальная остаточная толщина каждого сегмента.

**P10–P90**:
Интервал между десятым и девяностым процентилями квантильных моделей. Покрытие не
откалибровано. _Не говорим_: гарантированные границы.

**Приоритет проверки**:
Первые 10% самых тонких сегментов трубы — относительный порядок для дополнительного осмотра.
_Не говорим_: аварийный сегмент, вероятность отказа.

**Квадрат корреляции Пирсона (r²)**:
Квадрат линейной корреляции прогноза и факта; основная метрика валидации.
_Не путать_ с коэффициентом детерминации R².

**MAE**:
Средняя абсолютная ошибка прогноза в миллиметрах.

**Снимок**:
Набор файлов конвейера, который загрузил backend. Идентификатор снимка — хэш содержимого
файлов; он показывает, из какой версии данных взято число.
