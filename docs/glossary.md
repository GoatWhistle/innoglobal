# Прогноз деградации трубопроводов

Термины кейса прогнозирования остаточной толщины стенки. Источник: ТЗ, с. 1–3.

## Труба и обследования

**ВТД**:
Внутритрубная диагностика: обследование трубы, предоставляющее измерения её состояния.
Предыдущее ВТД может быть исходными данными, контрольное ВТД на дату прогноза скрыто.

**Сегмент**:
Интервал трубы длиной 10 м, для которого требуется один прогноз минимальной остаточной толщины.
Последний интервал может быть короче, если длина трубы не кратна 10 м.
_Не путать_ с точкой замера: одному сегменту могут соответствовать несколько измерений.

**Номинальная толщина**:
Исходная проектная толщина стенки трубы; во втором кейсе она служит отправной точкой при вводе.
_Не путать_ с измеренной толщиной: номинал не подтверждает фактическое состояние стенки.

## Прогноз и оценка

**Минимальная остаточная толщина**:
Наименьшая толщина стенки в пределах сегмента на заданную дату, выраженная в миллиметрах.
Она не описывает распределение повреждения по окружности трубы.
_Не говорим_: средняя толщина, глубина дефекта.

**Дата прогноза T**:
Дата, на которую оценивается минимальная остаточная толщина каждого сегмента.
Измерения контрольного ВТД этой даты предназначены для оценки результата.

**P10–P90**:
Интервал между десятым и девяностым процентилями прогнозного распределения.
Его фактическое покрытие требует отдельной проверки по наблюдениям.
_Не говорим_: гарантированные границы.

**Приоритет проверки**:
Относительный порядок сегментов по выбранному правилу отбора для дополнительного рассмотрения.
Он сам по себе не устанавливает вероятность отказа или допустимую толщину.
_Не говорим_: аварийный сегмент, подтверждённая утечка.

**Квадрат корреляции Пирсона (r²)**:
Квадрат коэффициента линейной корреляции прогнозов и фактических значений, метрика оценки в ТЗ.
_Не путать_ с коэффициентом детерминации R²: это другая метрика.

**Синтетический пример**:
Искусственно сформированные данные для демонстрации поведения интерфейса.
Они не являются результатом обследования трубы или проверкой точности модели.
