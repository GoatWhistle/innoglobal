# Знак и логотип

duppel пишется только строчными. Знак «то же самое» состоит из двух клиновидных штрихов, как кавычка
〃 и двойной штрих секунд ″. Второй штрих опущен на 7 модулей из 27: модель и показания разошлись,
это утечка.

| Файл | Что это | Где используется |
|---|---|---|
| `symbol.svg` | Знак без слова. `viewBox="1.75 0 46 46"`, два пути: `mark-base` (первый штрих) и `mark-accent` (второй, опущенный). Цвета не заданы, их задаёт CSS | Favicon и иконки приложения, знак в интерфейсе и README |
| `wordmark-light.svg` | Логотип для светлого фона: слово `duppel` в кривых (Schibsted Grotesk 800) и знак верхним индексом. Чернила `#0f0e0d`, акцент оксблад `#a3271e` | README, материалы на светлом фоне |
| `wordmark-dark.svg` | Та же геометрия для тёмного фона. Бумага `#f7f6f4`, акцент янтарь `#ffac2e` | README в тёмной теме GitHub, материалы на тёмном фоне |
| `src/build.py` | Генератор всех трёх SVG | Запускается вручную после изменения геометрии |
| `src/SchibstedGrotesk-800.ttf` | Шрифт слова, лицензия SIL OFL 1.1 | Только для логотипа; интерфейс набран Onest |

## Геометрия

- Модуль равен единице координат `symbol.svg`. Штрих высотой 27 модулей, голова шириной 11, шаг между
  штрихами 14, второй штрих ниже первого на 7.
- В логотипе знак стоит после слова верхним индексом: высота штриха 0,64 высоты прописной, верх
  по высоте прописной, отступ от слова 0,2 высоты прописной.
- Цвета повторяют токены `--brand-ink` и `--brand-accent` из `frontend/src/shared/styles/tokens/`.

## Как пересобрать

```bash
python docs/brand/src/build.py
```

Скрипту нужен `fontTools` (`pip install fonttools`). Он перезаписывает `symbol.svg`,
`wordmark-light.svg` и `wordmark-dark.svg`; руками эти файлы не правят. После пересборки:

- `cd frontend && npm run brand:assets` пересобирает favicon, иконки приложения и карточки для соцсетей;
- геометрию знака в `<template id="brand-mark">` (`presentation/src/shell.html`) обновляют из `symbol.svg`.
