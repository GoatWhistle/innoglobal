# Данные и безопасность

Что нужно знать службе ИБ перед установкой во внутреннем контуре.

**Читайте, если** согласуете установку или подключение реальных данных · **Связано:**
[Запуск](running.md) · [Архитектура](architecture.md) · [Помощник](assistant.md)

---

## Куда уходят данные?

Никуда. Конвейер, хранилище, API и интерфейс работают на одной машине. Карта и 3D-сцена строятся
из данных снимка без внешних тайлов и CDN; шрифты и библиотеки собраны в образ интерфейса.
Единственный внешний вызов — языковая модель помощника, и только если её явно включить
(`LANGUAGE_MODEL=codex`). Без неё помощник работает локально.

## Что видно снаружи машины?

Compose публикует порты только на `127.0.0.1`: интерфейс на 8080, API на 8000. Чтобы открыть стенд
в сети, поставьте перед ним свой обратный прокси с TLS и авторизацией.

| Свойство | Как сейчас |
| --- | --- |
| Пользователи и роли | Нет: доступ к адресу даёт доступ ко всем данным |
| API | Только чтение снимка; запись — история помощника и версии дашбордов в томе `assistant-state` |
| Процесс backend | Непривилегированный пользователь `app` (uid 1000) |
| Исходные CSV | Подключены к конвейеру только для чтения (`./data:/input:ro`) |
| Секреты | Только в `.env` сервера; во фронтенд не передаются |
| Ответы с ошибками | Код и короткое сообщение, без трассировок |

## Что делает помощник с языковой моделью?

Модель получает вопрос, контекст выбранной трубы и компактные результаты инструментов, а не
файлы целиком; пакет доказательств ограничен 32 000 символами. У агента есть только девять
инструментов приложения, без shell, веб-поиска и доступа к файлам. SQL-инструмент принимает один
`SELECT` и выполняет его в отдельной DuckDB в памяти над представлениями только для чтения:
5 секунд, 256 МБ, не больше 50 000 строк. Подробности: [помощник](assistant.md).

Перед подключением модели к реальным данным убедитесь, что договор с провайдером допускает
передачу этих данных.

## Как обновить данные?

Положите новые выгрузки в `data/` в тех же форматах ([данные](data-contract.md)), пересчитайте
прогноз и перезапустите backend:

```bash
docker compose run --rm pipeline python -m pipetwin
docker compose restart backend
```

Backend проверяет полноту и согласованность снимка до того, как начнёт его отдавать. Новый
идентификатор снимка показывает, что данные сменились.
