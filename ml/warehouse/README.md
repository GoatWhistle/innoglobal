# Хранилище (DuckDB)

Аналитическая БД с исходными данными, очищенными по слоям. Один файл, без сервера.

```bash
uv run --project ml python ml/warehouse/build.py     # data/*.csv -> warehouse/pipetwin.duckdb (~2 с)
uvx --from duckdb duckdb warehouse/pipetwin.duckdb   # SQL-консоль (или DBeaver / Python duckdb)
```

Сборка идемпотентна (`create or replace`). Код завершается с ошибкой, если упала проверка уровня `error`.

## Слои

| Схема | Что | Правило |
|---|---|---|
| `raw` | CSV как есть, все поля `VARCHAR` + `_row_num`, `_source_file`, `_loaded_at` | Ничего не меняем, исходник всегда можно восстановить |
| `core` | Типизированные очищенные сущности с английскими именами и единицами в названии | Одна сущность — одна таблица, ключи уникальны, ссылки целы |
| `quarantine` | Отбракованные строки с колонкой `reason` | `raw = core + quarantine`: строки не теряются молча |
| `mart` | Витрины для модели и EDA | Строятся только из `core` |
| `dq` | `dq.check_result` — результаты проверок качества последней сборки | |

### core
| Таблица | Ключ | Источник |
|---|---|---|
| `pipe` | `pipe_id` | паспорт `pot_south`: ~90 полей для аналитики (структура сети, материал, проект, обследования, ингибирование, очистка, ревизии, отказы) + длина профиля, число сегментов |
| `pipe_attribute` | `pipe_id, attribute_no` | **весь** паспорт в длинном виде: 2 908 непустых ячеек всех 286 колонок с полным названием и группой |
| `route_point` | `pipe_id, dist_m` | профиль трассы `altitudes_south` |
| `segment` | `pipe_id, segment_id` | сетка 10 м, `z_center_m` — линейная интерполяция профиля; уклон, высота относительно окрестности ±100 м, локальная низина |
| `ili_run` | `pipe_id, run_date` | пропуски ВТД: число дефектов, модальная стенка, флаг пригодности для обучения |
| `ili_feature` | `feature_id` | особенности и дефекты ВТД со **всеми** полями отчёта: класс, категория, трубная секция, расстояние до шва, опорные точки, ремонт, кластер |
| `ili_reference_point` | `pipe_id, name` | опорные точки ВТД (задвижки, тройники, вантузы, знаки) с положением на участке и кодом узла |
| `ut_measurement` | `measurement_id` | УЗТ |
| `corrosion_coupon` | `coupon_row_id` | образцы-свидетели и химия воды `repcorr_south` (все 59 колонок) + привязка к трубам паспорта |
| `regime_daily` | `pipe_id, calc_date` | техрежим, одна строка на сутки |

### mart
- `ili_segment` — посегментный результат каждого пропуска (`y_min_residual_mm` — таргет модели) плюс число внутренних и внешних дефектов, максимальная глубина и `is_training_eligible`. Совпадает с `prepare.segment_targets` везде, кроме очищенных строк.
- `regime_monthly` — помесячные агрегаты режима: доля простоя, доля медленного потока, обводнённость и т.д.

## Правила очистки

**ВТД**
- `Defect Depth in %` в пропусках 2018-09-23 записан **долей** (0.249 = 24.9%). Шкала определяется автоматически по согласованности `residual ≈ wall·(1 − depth)` и приводится к процентам. После этого согласованность 100%.
- Дефекты с `dist < 0` или за концом профиля → quarantine `out_of_pipe_bounds` (251 строка, совпадает с флагом выгрузки `is_beyond_pot`; 224 из них — ВТД 2023 трубы `1250011604`).
- Точные дубли (участок, дата, дистанция, угол, глубина, размеры, описание) → quarantine `duplicate`.
- Тип дефекта нормализован: `Внутренний`/`внутр.` → `internal`, `Внешний`/`внешн.` → `external`.
- Пропуск раньше даты ввода трубы → `ili_run.is_training_eligible = false` (ВТД 2014 нитки Куст-2 снят со старой трубы 4.5 мм, а действующая труба 8 мм введена в 2016). Правило общее, без хардкода направления.

**Техрежим**
- Несколько расчётов за сутки → остаётся последний, остальные в quarantine.
- Ноль там, где он физически невозможен → `NULL`: давление (30% строк), температура смеси, плотность, вязкость.
- Давление выше допустимого рабочего из паспорта → `NULL` (сбои до 4 947 атм).
- Скорость > 5 м/с → `NULL`. Расход > 20 медиан участка → `NULL` для всего блока расхода и скорости (сбойный день 2018-10-07, q = 25 732 на всех трубах).
- Простой (`q = 0`) — реальное состояние: флаг `is_downtime`, значения остаются 0. Агрегатам скорости простой не подмешивается (`mart.regime_monthly`).

**Профиль:** дубли дистанции → quarantine.

**Коррозионный мониторинг:** `Protected Segment Name` нормализуется в имя направления паспорта (`'Куст-1 -> т.вр. ДНС-1'` → `'Куст-1 - ДНС-1'`), флаг `matches_pipe_direction`. Эти две колонки читает модель, они не менялись.

### Привязка мониторинга к трубам (`corrosion_coupon.link_*`)

Из 9 участков мониторинга в паспорте только 1, у 82 образцов ID нет. Связь восстанавливается по топологии сети, правила общие (без ID в коде), применяются по порядку:

| `link_level` | Правило | Образцов |
|---|---|---|
| `section` | ID участка есть в паспорте | 83 |
| `section_assigned` | ID нет, тот же сегмент защиты есть ровно у одного участка паспорта → ID присвоен (`section_id_filled`) | 31 |
| `tie_in` | узел участка (`УЗ-19`) найден в опорных точках ВТД трубы → поток входит в трубу на `linked_position_m` | 109 |
| `upstream_node` | участок сходится в начальном узле участка паспорта (`УЗ-1 КПСОД`) | 23 |
| `upstream_segment` | сегмент защиты = направление паспорта, сам участок в паспорт не попал | 43 |
| `upstream_via` | общий узел с участком, привязанным правилами выше | 88 |
| `protection_zone` | совпадает только зона защиты ингибитором (слабая связь) | 67 |
| `water_line` | площадка КНС / обводнённость 100 %: водовод, синтетический ID 9900000001 | 51 |

Ключ к врезкам — `core.ili_reference_point`: опорные точки ВТД 2014 трубы Куст-2 – ДНС-1 «тройник 0.6 км УЗ-19» и «тройник 2.7 км УЗ-20» по расстояниям до них стоят на 624.9 м участка 1250013653 и 5.4 м участка 1250013657 (разброс 0.1 и 1 м). Узлы чистятся от скобок (`УЗ-17(ЗКЛ-4)` → `УЗ-17`), суффикс сохраняется: `УЗ-17` и `УЗ-17 КПСОД` — разные узлы. Для каждого образца в `link_evidence` записано, чем подтверждена связь. Все 495 образцов привязаны (`coupon.unlinked` = 0).

**УЗТ:** флаг `is_plausible = thickness ≤ номинал · 1.15`.

**Описания:** у всех таблиц `core` и добавленных колонок есть `comment` (`sql/60_comments.sql`), видно в `duckdb_columns()` и DBeaver.

## Что нашли проверки (не чинится автоматически)

- **УЗТ: 67 из 67 замеров толще номинала в 1.6–2.7 раза** (12–16 мм на трубах 4.5/8 мм). Данные нельзя использовать как остаточную стенку: либо замеряли другой элемент (фитинг, катушку), либо поле означает другое.
- **В техрежиме 30% суток отсутствуют**: дыры до 398 дней (ЦППН, по 2017-04-03), до 195 дней (Куст-1, по 2013-07-25). Режим всех труб начинается позже ввода больше чем на год.
- **В пропуске 2018 трубы `1250022871` стенки 7.5/8/9 мм вперемешку.**
- **У 92 из 400 образцов** дни экспозиции не совпадают с «снятие − установка».
- **338 из 495 образцов** относятся к направлениям вне наших 16 участков; у ДНС→ЦППН (труба без ВТД) образцов нет.
